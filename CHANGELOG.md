# Changelog - Tanya UserBot

## [2.0.0] - 2026-10-07

### Added
- Full modular plugin system
- JSON based database (notes, filters, AFK, gban, sudo, welcome, auto_reply)
- Tagall, Spam, Raid systems
- Auto Reply + Filters + Notes
- AFK with auto response
- Welcome & Goodbye messages
- Global Ban + Sudo system
- Art & Text styles (font, ascii, vapor, zalgo, carbon)
- Broadcast system
- Locks, Anti-flood, Blacklist
- Weather, Calculator, Hash, Base64 tools
- Profile clone
- Keep-alive Flask server for Render
- Full documentation (INSTALL, COMMANDS, CONTRIBUTING)
