# 🤖 Tanya UserBot v2.0

**Full Advanced • Powerful • Modular Telegram UserBot**  
Optimized for **Render** Web Service (Free Tier)

## ✨ Features (100+ Commands)

- **Admin**: ban, kick, mute, promote, purge, pin, locks
- **Tagall**: tagall, all, admin tag
- **Spam / Raid**: spam, delayspam, raid, replyraid, cspam
- **Auto Reply + Filters + Notes**
- **AFK** with auto response
- **Welcome / Goodbye** messages
- **Global Ban + Sudo** system
- **Art**: fonts, ascii, vapor, zalgo, carbon
- **AI**: Gemini + ChatGPT
- **Media**: YouTube + song download
- **Utils**: weather, calc, hash, base64, qr, tts, paste, remind
- **Fun**: ship, decide, memes, quotes
- **Broadcast**: gcast, usercast
- **Antiflood + Blacklist**
- **Clone profile**, eval, exec, restart

## 🚀 Deploy on Render

1. Generate String Session:
```bash
git clone https://github.com/Kartiknishad36/Tanya-user-bot.git
cd Tanya-user-bot
pip install telethon
python string_session.py
```

2. Render → New Web Service → Connect this repo
3. Build: `pip install -r requirements.txt`
4. Start: `python main.py`
5. Env Vars: `API_ID`, `API_HASH`, `STRING_SESSION`, `OWNER_ID`
