## \U0001f680 Deploy on Render

### 1. String Session
```bash
git clone https://github.com/Kartiknishad36/Tanya-user-bot.git
cd Tanya-user-bot
pip install telethon
python string_session.py
```

### 2. Render Web Service
- **Build:** `pip install -r requirements.txt`
- **Start:** `python main.py`
- **Env Vars:** `API_ID`, `API_HASH`, `STRING_SESSION`, `OWNER_ID`, `PORT=10000`

Full guide \u2192 [INSTALL.md](INSTALL.md)
